# Recomputing the Steen DNA-PAINT panel from localizations

The input is the authors’ public Picasso localization deposit for the 18-dye comparison. The starting measurements are coordinates and Gaussian-fit photon estimates from the original microscope. They carry the original spot thresholds, drift correction, alignment and manual selection. [Paper and methods](https://doi.org/10.1038/s41592-024-02374-8) · [Zenodo archive, CC BY 4.0](https://zenodo.org/records/10960858) · [Author analysis code](https://github.com/PhilippSteen/DNA-PAINT_analysis/tree/dad2df581be9)

## Run

Download `dye_analysis.rar` from Zenodo and verify it against the archive metadata. Place the extracted `39.dye_analysis` directory under `extracted/`. Keep the nested `reference_cy3b` directories. The measures use the `fig_2` and `fig_3` panels.

```bash
python3.12 -m venv .venv-palette
. .venv-palette/bin/activate
python -m pip install numpy==2.5.4 scipy==1.18.1 h5py==3.16.0 numba==0.68.1 lmfit==1.3.4 PyYAML==6.0.3
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python -m analysis.palette_raw_run \
    --root extracted --index docs/data/palette-manifest.json --cache .cache/palette-cases --workers 4 \
    --output docs/data/palette-raw.json
python -m unittest discover -s tests -p test_palette_raw.py -v
```

The public manifest supplies a SHA-256, byte count and CRC32 for every HDF5. Incremental processing can instead use `--index quick-index.json --watch` with an archive member index containing `path`, `bytes` and an integer `crc`. Wait for a CRC-verified extractor to finish each member before putting it in the input directory. Rerunning the command reuses atomically completed acquisitions when scripts, per-member identities and companion metadata match. The JSON records the original paths, member checksums and related duplicate members. Full acquisition and picked-region files overlap.

The released calculation verified **435 HDF5 and 435 YAML SHA-256 digests**. It covers 108 principal acquisitions and one additional Cy3B field from 18 dyes. It fitted 163 target or reference fields. The full and picked tables together contain 491,953,862 rows, including rows repeated across file roles. Across the selected target tables we identified 17,250,271 consecutive-frame events and 9,867,043 interior frames. All 54 paired NPC specificity calculations use diameters recorded in the original YAML. Of the 22 principal acquisitions with increased counts in the final fifth, 18 corresponding source cells report zero drop. The JSON keeps the sign of the measured change. ## Panels and endpoints

| Input and metric | Computation |
|---|---|
| Fig. 2 target field and selected single docking sites | Three measurements for each dye, each with a full-field and a single-binding-site HDF5. Use the field to fit NeNA and the selected sites to measure photons, event lengths, drop and apparent destruction. |
| Fig. 3 target and reference | Three measurements per dye. Each target round has full-field, picked NPC and cytoplasm files. The corresponding Cy3B round has the same three file roles. Use the target field for the primary NeNA endpoint and fit the reference field separately for QC. An additional `cy3b/n4_fig3` field has a target triple only and is excluded from repeat averages and pair selection. |
| Center photons | Sort the selected rows by pick and frame. A binding event is a run of consecutive frames in a single pick. Average the positive fitted photons over the interior frames of runs of length ≥3. Both endpoints of each run have partial exposure. The published duration is 100 ms per frame. |
| Event photons | Sum the deposited fitted photons across every frame of each run and average finite event totals. This includes edge frames and can include overlapping emitters at an NPC. The JSON also includes the median total and pooled edge-frame mean. Camera fitting and missed detections affect both photon measures. |
| Center-frame SBR | Integrate the fitted elliptical Gaussian over a central 1 × 1 pixel area. Multiply center photons by `erf(0.5/(√2 sx)) × erf(0.5/(√2 sy))` and divide by fitted per-pixel background. Average positive finite values. |
| Kinetics | For each pick, fit the empirical CDF at ranks 0 through 1 to `1 − exp(−t/τ)`, using the original 200-frame initialization and LMFit’s MINPACK settings. An individual fit requires at least two observations. Bright-time input is the consecutive-run length. Dark-time input in the released code is the difference between successive event **starts**. Average finite positive fits with equal weight per pick and convert camera frames to seconds at nominal 100 ms. |
| Drop in localizations | Apply the author code’s inclusive frame boundaries to the selected origami single sites or target NPC picks. Report `100 × (1 − final-fifth / first-fifth count)`. A negative percentage is an observed increase. The YAML frame count sets the acquisition duration. The nominal origami and NPC durations are 20,000 and 30,000 frames, respectively. The NPC drop is a parallel calculation on selected NPCs. The Nup96 methods give no separate procedure for this endpoint. |
| Apparent docking-site destruction | For each eligible site, divide the frames from its last localization to acquisition end by its fitted dark time. Fit an exponential to the positive ratios in a histogram with 0.5-wide bins. Count sites at or above `max(4, 4μ)`, where μ is the fitted exponential mean. Apply the published chance-tail correction of `100 × exp(−4)` percentage points. The released code retains sites with failed fits in the denominator. Both the full and fit-eligible denominators, fitted μ and tail count are available for inspection. |
| Relative NPC specificity | Divide NPC localization density by cytoplasm density in each round, then divide the target ratio by the paired Cy3B ratio. Use per-pick areas or diameters when available. With transferred same-sized selections, area factors cancel between rounds and row counts per nonempty pick suffice. Each replicate gives its area assumption and pick counts. |
| NeNA precision | Tally same-group next-frame pair separations below one camera pixel, using 1,000 bins. When the field has no group column use all localizations. Preserve Picasso’s 100 integer-sized source batches and corresponding terminal remainder. Fit the two-component historical model with the original initialization and convert its fitted `s` to nm using the camera pixel size. The JSON retains the full fit, pair count, residual and initialization. On CF488A origami n1 and Abberior STAR 488 NPC n1, the accelerated histogram and fitted widths matched direct execution of the pinned source for all 1,000 bins, yielding 4.728692 and 9.138814 nm, respectively. [Picasso implementation from 2023](https://github.com/jungmannlab/picasso/blob/deab0c6e31c544fc56d1e4d0ccc8e00348dcae92/picasso/postprocess.py#L315-L388) |

`coverage` and `replicates[].files` identify exactly which files were read. `replicates[].counts` reports the pick, event, center-frame and fitted-group counts, and `dyes[].metrics` gives the arithmetic mean and sample SD across principal repeat measurements. Shared Cy3B reference files induce dependence between specificity estimates. The authors discarded fields with poor Cy3B alignment precision, hand-refined NPC selections and manually picked cytoplasmic regions. The pair evaluation concerns acquisitions and regions retained by that procedure. Raw recomputation can differ from the published rounded cells. Both series have per-repeat values and source identities. [Steen et al., Nup96 methods](https://doi.org/10.1038/s41592-024-02374-8) · [Released kinetics and intensity definitions](https://github.com/PhilippSteen/DNA-PAINT_analysis/blob/dad2df581be9/core_functions.py) · [Released specificity calculation](https://github.com/PhilippSteen/DNA-PAINT_analysis/blob/dad2df581be9/Unspecific_binding_NPC.py)

For CF488A origami repeat 1, running the deposited `GroupCalcs` directly yielded 4,418 center frames, 5,072.409 mean photons and 3.58772 mean SBR. The corresponding public source cells contain 4,666 photons (E12) and 3.59 SBR (E22). Both NeNA implementations yielded 4.728692 nm, which rounds to the published 4.73 nm (E7). The brightness discrepancy therefore persists with the authors’ deposited code. [Figure 2 source workbook](../docs/data/steen-figure2.xlsx)

### Two NeNA discrepancies

| Target field | Deposited repeat values (nm) | Published repeat values (nm) | Acquisition identity |
|---|---|---|---|
| JF585, fixed-cell NPC | 14.9422, 12.6598, 4.3674 | 14.9, 17.3, 19.9 (Fig. 3 D2–D4) | Repeat 3’s field and NPC picks both name `C3_JF585_100pM_Tx_20mW_1_MMStack_Pos0.ome.tif` in their YAML. The target field has 4,029,089 rows. Its distinct Cy3B reference names `C3_Cy3b_100pM_adTx_20mW_2_MMStack_Pos0.ome.tif` and gives 3.8838 nm. |
| ATTO643, DNA origami | 3.0958, 3.7029, 8.8205 | 3.1, 3.7, 3.3 (Fig. 2 L7–L9) | Repeat 3’s field and site picks both name `S2_Atto643_300pM_Tx_70mW_1_MMStack_Pos0.ome.tif` in their YAML. The target field has 1,203,361 rows. |

Direct execution of the 2023 Picasso implementation on both repeat-3 targets reproduced every histogram bin and the respective 4.367402 and 8.820496 nm fits. The second fitted width (`sc`) is 24.0164 and 3.0990 nm, respectively. The source code reports its first width (`s`). Reordering repeats cannot reconcile either series with the workbook. The worksheets label repeats numerically and provide no corresponding input filenames, software build or fitted parameter tables. The cause of these differences remains unresolved.
